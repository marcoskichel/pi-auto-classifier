# ASD-STE100 Simplified Technical English

The reply must follow these rules.

- Use active voice ("The tool writes the file", not "the file is written").
- Use simple verb forms: present, past, future. No perfect tenses, no -ing clauses.
- One topic per sentence. One instruction per sentence.
- Keep instruction sentences at 20 words or fewer, descriptive sentences at 25 or fewer.
- Use simple, common words. No jargon unless the domain requires it.
- Do not use vague words: "appropriate", "relevant", "as necessary".

## Judging

Minor deviations are acceptable. Fail only for clear violations: passive
voice throughout or consistently long, tangled sentences.
